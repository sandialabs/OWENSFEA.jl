API Map

This page maps the main user-facing API. Complete docstrings are grouped by source file on Autodocs by Source.

Model Data

NamePurpose
FEAModelSolver options, boundary conditions, joint transforms, nonlinear parameters, and nodal terms.
MeshNode coordinates, connectivity, element type metadata, and structural indexing.
OrtElement orientation helper data.
SectionPropsArraySpanwise section stiffness, mass, offsets, aerodynamic helper fields, and shear stiffness inputs.
ElPer-element section properties, lengths, angles, and rotational-effects flags.
DispDataDisplacement, velocity, acceleration, and previous-step state input.
DispOutDisplacement, velocity, acceleration, and optional modal state output.
ElStrainElement strain and curvature channels.
ROMReduced-order matrices and coefficient storage.

Analysis Entry Points

NamePurpose
modalLinearized modal/state-space analysis.
autoCampbellDiagramRPM sweep for OWENSFEA or GXBeam modal frequencies.
staticAnalysisStatic/steady displacement, strain, and reaction solve.
initialElementCalculationsCache initial element data before repeated analyses.
structuralDynamicsTransientFull-order transient structural dynamics.
reducedOrderModelBuild reduced-order model matrices.
structuralDynamicsTransientROMTransient structural dynamics in reduced coordinates.

Assembly And Mapping

NamePurpose
createJointTransformBuild reduced/full DOF transform from joint rows.
calculateReducedDOFVectorBuild a reduced DOF list from constraints.
constructReducedDispVectorMapBuild reduced displacement maps with BCs.
calculateBCMapMap prescribed BCs into equation numbering.
applyBCApply static/transient prescribed boundary conditions.
assembly!Assemble element matrix/vector into global arrays.
assemblyMatrixOnlyAssemble an element matrix without a load vector.
applyConcentratedTermsParse concentrated mass, stiffness, damping, and load terms.

Element And Postprocessing Helpers

NamePurpose
defaultTransverseShearStiffnessCompute default Timoshenko transverse shear stiffness.
transverseShearStiffnessInterpolate explicit or default shear stiffness at a quadrature point.
calculateTimoshenkoElementInitialRunInitial Timoshenko element calculation.
calculateTimoshenkoElementNLNonlinear/current-state Timoshenko element calculation.
calculateTimoshenkoElementStrainRecover element strain channels.
calculateTimoshenkoElementNLSSNonlinear selective-stiffness helper pinned by utility tests.
calculateStructureMassPropsIntegrate stored element mass properties.
calculateReactionForceAtNodeRecover reaction load at a node.
calculateStrainForElementsRecover strains for all elements.
findElementsAssociatedWithNodeNumberLocate element associations for a node.
getGPGauss quadrature points and weights.
calculateShapeFunctionsLinear/quadratic Lagrange shape functions and Jacobian.

Load Stepping And Modal Helpers

NamePurpose
updateLoadStepUpdate static load-step state after an iteration.
adaptiveLoadSteppingAdaptive load-step branch logic.
applyBCModalRemove constrained rows/columns for modal matrices.
extractFreqDampConvert eigenpairs to frequency, damping, and normalized mode-shape data.
constructReducedDispVecFromEigVecReconstruct reduced displacement vector from an eigenvector and BC map.
